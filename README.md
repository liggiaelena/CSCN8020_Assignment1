## Summary

This assignment implements four reinforcement learning problems in a single Jupyter Notebook, covering MDP design, dynamic programming, and Monte Carlo methods. All algorithms are based on Sutton & Barto (2018) *Reinforcement Learning: An Introduction* (2nd ed.).

| Problem | Topic | Points |
|---------|-------|--------|
| 1 | **Pick-and-Place Robot** — MDP formulation (states, actions, rewards) | 10 |
| 2 | **2×2 Gridworld** — Value Iteration, manual step-by-step + code verification | 20 |
| 3 | **5×5 Gridworld** — Standard Value Iteration vs In-Place Value Iteration | 35 |
| 4 | **5×5 Gridworld** — Off-Policy Monte Carlo with Weighted Importance Sampling | 35 |

## Assumptions and Design Decisions

| Topic | Decision |
|-------|----------|
| Discount factor (P2) | γ = 0.9 (not specified in the original problem) |
| Discount factor (P3 & P4) | γ = 0.9 (as suggested in P4 statement) |
| Reward convention (P3 & P4) | Reward received upon **entering** a state (next-state reward) |
| Terminal state value | V*(goal) = 0 — episode ends at s₄,₄, no future rewards collected |
| MC episodes | 50,000 episodes, max 500 steps per episode |
| MC seed | Fixed seed = 42 for reproducibility |
| In-Place VI convergence | Same θ = 1e-6 as Standard VI — verified to reach identical V* and π* |

---

## Known Limitations

- **MC approximation error**: Off-policy MC with a uniform behavior policy converges slowly for states far from the goal. Increasing `n_episodes` beyond 50,000 reduces the MAE vs Value Iteration.
- **Log files**: One example log (`logs/execution_20260611_165137.log`) is committed for grading. All other runtime logs are excluded via `.gitignore`. Re-running the notebook generates a new timestamped log in `logs/`.
- **Python 3.11+**: The notebook uses f-strings and `match`-free syntax compatible with Python 3.8+, but was developed and tested on Python 3.14.
